# Aviator Bot Pro — protótipo Android

Este é um projeto inicial para abrir no Android Studio. Ele contém:
- tela inicial;
- solicitação de permissão para janela flutuante;
- solicitação de autorização do Android para captura de tela;
- serviço de overlay;
- estrutura inicial de serviço de captura.

## Importante
Esta versão **não está pronta para uso real** e ainda não faz OCR nem coleta resultados. O pipeline de captura (VirtualDisplay/ImageReader + ML Kit) está marcado como TODO. O app não prevê resultados, não recomenda apostas e não automatiza apostas.

## Como abrir
1. Instale o Android Studio em um computador.
2. Abra a pasta `AviatorBotPro`.
3. Aguarde a sincronização do Gradle.
4. Execute em um aparelho Android de teste.

A compilação pode exigir atualização das versões do Android Gradle Plugin/SDK conforme o Android Studio instalado. Teste primeiro sem conta de apostas e não conceda permissões a apps de terceiros desconhecidos.
